# B 站与抖音手表播放优化计划

日期：2026-09-23。状态：待实施；本文不代表功能已交付或性能已提升。
初次审查基于 `6de70fd`，写入前已同步并复核 `e0936f1`。

## 目标与证据边界

降低首帧等待、弱网卡顿及单个 CDN 故障导致的播放失败，控制流量、内存和耗电。优先完善现有播放链路，再评估新格式与网络栈。

群内提供的是鸿蒙应用日志分析截图，并非完整原始日志或可复现抓包。截图中的 HTTP/3、0-RTT、专用接口及性能收益均待核验；其“qn32 = 1080P”与本仓库接口资料不一致，必须用实际返回宽高、码率和编码确认。不能把 B 站参数套给抖音，也不能硬编码截图中的签名 URL、IP 或 CDN 域名。

## 阶段 0：建立可比较的基线

- [ ] 两平台统一记录：解析接口耗时、连接/首字节耗时、首帧时间、卡顿次数与总时长、下载字节、缓存命中、播放错误及恢复结果。
- [ ] 记录实际分辨率、码率、编码、解码器、网络类型和候选节点序号；区分首次播放、缓存播放、后台预取。
- [ ] 只记录脱敏主机及错误类别，不记录 Cookie、令牌、完整签名 URL 或原始响应正文。
- [ ] 固定视频集合、手表型号/系统/版本，分别测 Wi-Fi 与可用的蓝牙共享网络；每场景至少 20 次，记录首帧 P50/P95。限速、丢包与故障注入优先在受控测试环境完成。

交付：可复现测量步骤、基线结果和脱敏日志样例。先有数据，再确定缓冲及吞吐阈值。

## 阶段 1：备用节点和有限恢复（最高优先级）

- [ ] B 站将主地址与 backup_url 传入播放源；抖音保留每个变体的完整 url_list，贯穿预取、播放及持久化模型，兼容旧缓存。
- [ ] 按接口返回顺序去重候选地址；只切换同一媒体表示的备用地址，不将不同码率、编码或分段当作字节等价资源。
- [ ] 连接失败、超时、节点 5xx 时尝试下一候选；每个候选一轮最多一次。设置整个恢复过程的时间预算，退出页面立即取消。
- [ ] 候选耗尽后最多刷新一次播放地址；403/明确过期按平台错误语义触发刷新，不把所有 403 都断定为过期。禁止无限重试。
- [ ] B 站增加同 CID 地址失效刷新，跳过旧地址缓存并合并并发请求；抖音复用现有刷新协调器。
- [ ] 切换保留位置与暂停状态，正确续传 Range；取消旧请求，避免旧请求结果覆盖新播放源。
- [ ] 保留完整签名参数，不替换域名拼接新 URL。刷新失败保留可诊断错误。

验收：模拟主节点超时、备用成功、全部失败、403、切换时退出和刷新并发；确认恢复有上限、无进度重置、无缓存污染。成功率和恢复耗时分别统计，不只看是否最终能播。

## 阶段 2：抖音按网络选流与预取预算

- [ ] 保留现有 540P/H.264 作为默认回退；使用近期有效媒体吞吐、实际码率和卡顿反馈选择候选，Wi-Fi 类型本身不代表带宽足够。
- [ ] 冷启动无测速数据时采取保守默认；弱网倾向较低码率，升档要求持续稳定并设置滞回，避免频繁切换。
- [ ] 第一版优先在切换视频时选流；同一视频中途切不同文件需要单独验证时间轴和缓存，不宣称自动无缝切换。
- [ ] 为预取设置字节、并发和时间预算，优先保障当前播放；评估 B 站按 60 秒估算的预取量是否挤占当前播放带宽。

验收：同一网络脚本和视频序列下，比较首帧 P95、卡顿、总下载量及画质；弱网应有可重复收益，正常网络不能出现明显回归。具体通过阈值在基线完成后写入测量报告。

## 阶段 3：DASH 与 H.265 实验

- [ ] B 站补齐音视频分轨所需字段（包括实际响应使用的字段别名、MIME、编码、初始化及索引信息），构建 Media3 可播放的媒体源；仅解析 URL 不等于完成 DASH 支持。
- [ ] 区分内容、分 P、清晰度、编码、音视频轨和表示的缓存键；保留 MP4 回退，覆盖只有音频、缺视频及不支持编码的响应。
- [ ] 抖音 H.265 仅对验证通过的硬件解码能力启用，检查分辨率、profile/level、帧率；失败回退 H.264，不因系统声明支持就全面开启。
- [ ] 实机比较首帧、掉帧、流量、温升与耗电；每项实验独立开关，默认沿用旧路径。

验收：音画同步、拖动、恢复、切节点和长时播放均通过；未经实机验证不得默认启用 H.265 或宣称省电。

## 阶段 4：网络栈实验（低优先级）

仅当测量显示连接建立是主要瓶颈且目标服务支持时，评估 Cronet/HTTP/3；分别测业务 API 与视频 CDN。计入包体、启动开销、手表兼容性和 UDP 不可用时的回退。连接复用不等于 0-RTT，API 使用 HTTP/3 也不证明视频下载使用 HTTP/3。

参考：[Media3 网络栈](https://developer.android.com/media/media3/exoplayer/network-stacks)。
