# Compose 1.3.3-1 发布审查

## 基线与范围

独立子 agent 对比上次 GitHub 正式发布 `v1.3.2-12` 与当前 Compose 分支，并复审本次修复。
基线到审查初始 HEAD `ffa032d5` 涉及约 431 个文件；本次重点检查蓝牙账号隔离、旧手机版兼容、云同步界面及发布配置，并非全面审计。
旧手表侧载包为 `1.3.3-final`，不能从版本名证明其精确源码；未把临时构建目录当作确定的发布基线。

## 发现与修复

1. P1：现有手机版不发送 `libraryAccountUserId`，绑定账号后无法同步。手表现在只在同一连接成功完成账号同步后允许无账号字段的旧请求；显式账号仍须匹配。失败握手和连接结束撤销授权。
2. P1：`clearLibrary` 未纳入资料账号检查。现在使用相同账号隔离规则。
3. P2：云同步默认隐藏后，既有界面测试仍期待该入口。调整默认隐藏与显式启用测试，并更新旧调试控件断言。
4. 复审补充：账号确认移至成功响应构造结束；正文批次与预览流逐帧检查当前请求账号。
5. 发布复现：加入 `watchrss.applicationId` 构建参数；签名凭据保持本机配置，参见 `../compose-release.md`。

最终只读复审未发现本轮修复新增的发布阻塞。

## 验证边界

- Release 单元测试：821 项通过，0 失败、0 错误、0 跳过。
- 仪器测试 Kotlin 源码编译通过；未运行完整设备仪器测试。
- 手机版 `1.3.0-1` 源码的常规同步顺序为持久连接、可选 IP 升级、账号同步、资料同步；本次兼容覆盖该同连接流程。
- 未验证真实资料库同步、单项操作、单向覆盖、断线自动恢复及播放流畅度。不宣称这些路径兼容或性能改善。
