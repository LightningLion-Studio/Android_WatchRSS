# Compose 1.3.3-2 发布审查

## 基线与范围

基线为上次正式发布 `v1.3.3-1`（`e2c87d4a`）。
本次只修复两个用户反馈，不含其他功能改动。

## 修复

1. 哔哩哔哩频道顶部遮挡：频道标题原为整行宽度，在圆屏顶部超出圆形可见区域。
   `BiliFeedScreen` 与 `BiliRssFeedScreen` 改用 `WatchPageTitle`：圆屏按标题所在高度的弦宽折行，每行四角留在圆内；方屏保持整行宽度。
   该组件取自 11-04 未发布的圆屏标题补丁，本次只采用哔哩哔哩频道标题部分。
2. 备忘录编辑文字看不清：编辑器绘制在阅读主题背景上，但正文与标题使用界面主题的 `onSurface` 颜色。
   浅色阅读背景下文字与背景同色。正文、标题改用阅读主题的正文、标题颜色，占位文字改用副标题颜色。

## 验证边界

- Release 单元测试：823 项通过，0 失败、0 错误、0 跳过；含 `WatchTitleFormattingTest` 新增的圆屏折行与弦宽用例。
- 同源码独立 Compose 包在 OWW242（466×466 圆屏）覆盖安装：哔哩哔哩频道标题两行的四角距圆心最大 218.5 px，半径 233 px。
- 同一设备切换浅色阅读主题后，备忘录编辑器输入的文字为深色，可与浅色背景区分；核对后恢复深色主题。
- 未运行完整设备仪器测试；正式包名 APK 未在设备上覆盖安装。

发布附件沿用 `v1.3.3-1` 的正式包名 `com.lightningstudio.watchrss` 与签名。
