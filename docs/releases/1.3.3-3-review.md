# Compose 1.3.3-3 发布审查

## 基线与范围

基线为 `v1.3.3-2`。
本次修复 OPPO 审核截图中的圆屏裁切，并修复同类首次使用页面的顶部标题，不含其他改动。

## 修复

1. 哔哩哔哩频道未登录页标题（审核截图 a）：`v1.3.3-2` 已用 `WatchPageTitle` 修复；本次复核未登录状态，标题两行与 ⓘ 均在圆内。
2. 哔哩哔哩扫码登录页（审核截图 b）：提示文字原距顶部 4dp，圆屏顶部被裁切。
   圆屏改用较小字号，并把提示与二维码作为一组垂直居中；`roundHintQrSidePx` 按圆计算二维码边长，使提示和二维码四角都留在圆内。方屏布局不变。
3. 抖音扫码登录页：代码核对发现底部提示“请使用抖音App扫码”在 16dp 边距下四角超出圆形。圆屏上下边距改为 28dp。未在设备上打开抖音。
4. 抖音频道无内容页 `PlatformEntryScreen` 标题“腕上RSS · 抖音频道”与日志上传隐私页标题“隐私及防诈说明”单行宽度超过顶部弦宽，改用 `WatchPageTitle`。

## 已核对、未修改

以下页面顶部标题按几何估算未明显超出圆形，本次不改：

- RSS / 抖音频道页 `FeedHeader`：首行宽度上限 150dp，顶部约 30dp 处弦宽约 156dp。
- 抖音扫码页顶部提示“请使用手机扫码”。
- 连接手机页 `RoundPage`：内容垂直居中，上下边距 26dp。
- 备忘录、首页：设备截图中标题在圆内。

  - 哔哩哔哩频道未登录页：标题两行四角距圆心最大 218.5 px，半径 233 px。

- 抖音扫码页、抖音无内容页、日志上传隐私页只做代码与几何核对，未在设备上截图。
